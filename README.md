# Tass & Mys – Katthotell

Det här är ett Java-program där man kan checka in katter på ett katthotell. Programmet kontrollerar att två katter inte har samma chipnummer och kan visa vilka katter som är incheckade.

Jag har använt klasser, objekt, privata variabler, getters, listor och metoder för att bygga programmet.
